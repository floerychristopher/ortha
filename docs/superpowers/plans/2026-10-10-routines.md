# Routinen und Habits Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Goals werden zu Habits in geordneten Routinen mit Zeitfenster; Today zeigt die aktuelle Routine und den nächsten Schritt; Streaks folgen „never miss twice“; Ruhetage als `·`.

**Architecture:** Schema v4 ergänzt `routines` sowie `goals.routine_id/position`, der Status `skipped` kommt hinzu. Die Regeln (Streak, aktuelle Routine, Tagesfortschritt, Ausklappen) sind reine Funktionen in `core/goal` und `core/routine`. `RoutineRepository` liefert fertige `RoutineSummary`s für die Views. TUI: Today bekommt einen Routinen-Abschnitt, `routines_view` ersetzt `goals_view`, dazu `routine_form` und ein Routine-Feld im Habit-Formular.

**Tech Stack:** wie bisher – C++20, FTXUI v6.1.9, SQLite, Catch2.

**Spec:** `docs/superpowers/specs/2026-10-10-routines-design.md`

## Global Constraints

- Alle Global Constraints der bisherigen Pläne gelten (C++20, Namespace `ortha`, keine Warnungen, Sentence case für Beschriftungen, Platzhalter und gedimmte Texte komplett klein).
- **Commits nur auf ausdrückliche Anweisung des Nutzers**, ohne `Co-Authored-By`. Commit-Schritte unten sind Vorschläge.
- Status-Zyklus überall: `open` → `done` → `missed` → `skipped` → `open`; `skipped` wird als `·` (Box `[·]`, gedimmt) angezeigt.
- Im Code heißt der Typ weiter `Goal`, in der Oberfläche „Habit“; Menüpunkt „Routines“.
- Uhrzeiten intern in Minuten seit Mitternacht; Anzeige `8:00`, `19:30–21:30` (Halbgeviertstrich).
- Vor jedem Task `git status` + betroffene Dateien neu lesen; nach jedem Task C++-Konzepte kurz im Chat erklären.
- Build/Test: `cmake --build build && ctest --test-dir build --output-on-failure` (der Stop-Hook prüft das zusätzlich).

## Review Focus

1. **Bestehende v3-Datenbank mit Goals und Verlauf** → nach der Migration hängen alle Goals in „My routine“ (00:00), Reihenfolge = Anlagereihenfolge, Verlauf und Symbole erhalten. Test in Task 3.
2. **Habit wird in eine andere Routine verschoben** → landet am Ende der neuen Routine, die alte Routine hat keine Lücke, die stört (Move up/down funktioniert weiter). Test in Task 3.
3. **Routine gelöscht** → ihre Habits verschwinden aus Today, Routines-Ansicht und Raster; Einträge bleiben in der DB. Test in Task 3.
4. **Ruhetag-Toggle auf einer Routine, in der schon etwas abgehakt ist** → nur offene Habits werden `·`; zweites Enter macht nur die `·` wieder offen, ✓/✗ bleiben. Test in Task 3.
5. **Zwei Routinen mit gleicher Startzeit / Zeitpunkt vor der ersten Routine** → stabile Reihenfolge nach Anlagezeit; vor der ersten gilt die erste als aktuell. Test in Task 2.

  struct Goal { ...; std::string routine_id; int position = 0; };  // comment: shown as "habit" in the UI
  class GoalRepository {
      // insert: position = end of its routine. update: saves routine_id; moving to another
      // routine puts the goal at the end of that routine.
      std::vector<Goal> in_routine(const std::string& routine_id);  // by position
      void move(const std::string& id, int delta);                    // -1 up, +1 down; no-op at the edge

  struct RoutineSummary {
      Routine routine;
      std::vector<GoalSummary> habits;   // by position
      RoutineDay today;
      int streak = 0;
  };
  class RoutineRepository {
    public:
      explicit RoutineRepository(Database& db);                 // migrates
      void insert(Routine&); void update(Routine&);
      void remove(const std::string& id);                        // soft delete incl. its goals
      std::optional<Routine> find(const std::string& id);
      std::vector<Routine> all();                                // by start, then created_at
      // All routines with their habits; scheduled_only: only habits scheduled on `today`
      // and only routines that have at least one of them (Today view).
      std::vector<RoutineSummary> summaries(GoalRepository& goals, Date today, bool scheduled_only);
  };
